# 录音功能操作指南

给家长和维护者使用。日常操作按本页执行；错误处理见[录音排错指南](speech-troubleshooting.md)，代码和保存规则见[技术说明](speech-evaluation.md)。

## 先确认环境和档案

| 项目 | 当前配置 |
| --- | --- |
| 开发者工具导入目录 | 仓库根目录 `xcx-susu-learning/`，包含 `miniprogram/` 和 `cloudfunctions/` |
| 云开发环境 | `prod-d4gpmzbyg28ead01d` |
| 评分及录音函数 | `speech-evaluate` |
| 临时文件清理函数 | `speech-cleanup` |
| 爸爸的录音档案 ID | `dad` |
| 酥酥或妈妈代酥酥练习的档案 ID | `susu` |

**微信账号决定谁有权限，档案 ID 决定录音和分数存在哪里。** 相同 `learnerId` 共用一份档案，不同 ID 的录音、成绩和每日额度隔离。妈妈自己练习若也绑定 `susu`，成绩会影响酥酥的最高分录音；要分开就指定不同 ID。

## 1. 开通一个微信账号

1. 用要开通的微信账号进入小程序，首页底部打开 **家长录音设置**。
2. 点击 **申请开通此账号**，复制页面显示的申请码。已经登记过的账号直接复制现有申请码。
3. 在微信开发者工具打开 **云开发 → 数据库 → speech_family**，确认是本页列出的环境。
4. 按 `requestCode` 找到与申请码完全一致的记录，编辑下面两个字段：

   | 字段 | 类型 | 示例 |
   | --- | --- | --- |
   | `enabled` | 布尔值 | `true` |
   | `learnerId` | 字符串 | 爸爸填 `dad`；酥酥或妈妈填 `susu` |

5. 保留文档 ID、申请码及其他字段，保存。
6. 回到小程序点击 **刷新权限**，确认显示「当前录音档案：dad」或「当前录音档案：susu」。退出再进入课程，在「穿衣与整理」跟读活动中检查录音按钮。

成功标准：设置页显示正确档案，能够录音和取得真实评分。`enabled` 必须是布尔值，不能是字符串 `"true"`。新申请的 `learnerId` 默认为空，批准时要填写。

如果开发者工具和手机显示的申请码不同，分别按各自申请码批准对应记录；不要根据模拟器里已开通就认定手机也已开通。

## 2. 修改档案或撤销某人权限

**切换档案：** 按申请码找到该账号的 `speech_family` 记录，将 `learnerId` 改为目标 ID，保留 `enabled: true`。在小程序刷新权限，并退出再进入课程。

档案 ID 为 1–32 位小写字母、数字、下划线或连字符，以字母开头，例如 `dad`、`susu`、`mom`。只在后台编辑，前端没有任意切换档案的入口。

修改绑定不会移动、复制或删除已保存的录音和分数。例如从 `susu` 改成 `dad` 后，旧数据仍属于 `susu`；`dad` 没有数据时从空档案开始。

**撤销权限：** 只把对应记录的 `enabled` 改成布尔值 `false`。不要为撤销一个账号而删除共享成绩或录音。云端后续请求会检查权限，已经下载到本机并开始播放的短音频不会被远程强制中断。

## 3. 更新云函数和小程序

根据改动范围更新对应部分：

| 改动 | 需要做什么 |
| --- | --- |
| 评分、数据库写入、权限、保存或回放逻辑 | 部署 `speech-evaluate` |
| 临时录音清理逻辑 | 部署 `speech-cleanup` |
| 定时器名称或周期 | 更新并上传 `speech-cleanup/config.json` 的触发器 |
| 页面、按钮、动画、客户端评分流程 | 编译、预览并上传新版小程序 |
| 只修改账号 `enabled` / `learnerId` | 保存数据库记录，客户端刷新权限并重新进课；无需部署 |
| 新增可评分课程或改变评分目标 | 构建清单，更新评分函数与客户端；内容发布另按课程指南执行 |

部署一个函数：

1. 微信开发者工具中展开 **cloudfunctions**，确认已选择正确云环境。
2. 右键目标函数文件夹，选择 **上传并部署：云端安装依赖**，等待成功提示。
3. 在云开发控制台检查该函数配置，保留现有环境变量；内存 **256 MB**，执行超时 **40 秒**，Node.js **18 或更新**。
4. 有客户端改动时点击 **编译**，用手机预览或体验版验证。开发者工具编译只影响开发预览；给家人更新需要上传新版小程序并按原有流程发布/分发体验版。

评分等待优化需要同时更新 `speech-evaluate` 和小程序。只部署函数或只更新课程包，不能完整启用新的客户端流程。

## 4. 查看和设置环境变量

在 **云开发 → 云函数 → 对应函数 → 配置/环境变量** 中编辑。不要用一个函数的配置覆盖另一个函数。

| 函数 | 环境变量 | 值或用途 |
| --- | --- | --- |
| `speech-evaluate` | `SPEECH_ENABLED` | `true` |
| `speech-evaluate` | `SPEECH_STORAGE_PRIVATE` | 存储已配置为私有后填 `true` |
| `speech-evaluate` | `SOE_APP_ID` | 开通智聆口语评测账号的腾讯云数字 AppID |
| `speech-evaluate` | `SOE_SECRET_ID`、`SOE_SECRET_KEY` | 该腾讯云账号的 API 密钥，仅放后端 |
| `speech-evaluate` | `SPEECH_DAILY_LIMIT` | 建议 `60`，每份档案每天的预约次数上限 |
| `speech-evaluate` | `SPEECH_GLOBAL_DAILY_LIMIT` | 建议 `1000`，环境每天的总预约次数上限 |
| `speech-cleanup` | `SPEECH_CLEANUP_ENABLED` | `true`；此函数只需要这一个自定义变量 |

微信小程序 AppID（以 `wx` 开头）不是 `SOE_APP_ID`。云环境 ID 也不是 AppID。现有录音、评分均已开通成功时，不需要为普通代码更新重新申请这些服务或更换密钥。

## 5. 上传定时触发器

清理函数部署成功，不代表定时触发器已经上传。

1. 回到开发者工具左侧文件列表，展开 **cloudfunctions → speech-cleanup**。
2. **右键其中的 config.json 文件**，选择 **上传触发器**，等待成功。这个入口不要求先在云控制台找到「添加触发器」按钮。
3. 核对该文件的触发器配置：

   ```json
   {
     "name": "speech-recording-cleanup",
     "type": "timer",
     "config": "0 0 * * * * *"
   }
   ```

表达式共七段，表示每小时整点执行。已有同名触发器时使用现有配置，不重复创建。不需要 HTTP 触发器。

右键没有该菜单时，先确认右键的是函数下的 `config.json` 文件，且导入的是仓库根目录、`cloudfunctions` 已识别为云函数目录并选择了云环境；仍无菜单时记录开发者工具版本和菜单截图排查。

成功标准：后续整点在 `speech-cleanup` 日志中出现成功调用。没有待清理文件时 `deleted: 0` 是正常结果。不要用小程序手动调用来验证定时器，清理入口会拒绝小程序身份。

## 6. 首次配置数据库和存储

已有环境正常工作时无需重复创建。新环境按以下顺序配置：

1. 将环境绑定本小程序，确认该腾讯云账号已经开通「智聆口语评测（新版）」英文能力。
2. 建立五个数据库集合：`speech_family`、`speech_recordings`、`speech_quotas`、`speech_attempts`、`speech_summaries`。
3. 每个集合的客户端权限均配置为：

   ```json
   { "read": false, "write": false }
   ```

4. 在云开发 **存储 → 权限/安全规则** 单独设置客户端不可读、不可写，同样使用上述规则。数据库权限不会自动应用到文件存储。后端通过服务端 SDK 访问；不把录音设为公开读取。
5. 确认正式录音没有自动过期的存储生命周期规则，再设置 `SPEECH_STORAGE_PRIVATE=true`。这个变量是人工确认开关，本身不会改变存储权限。
6. 配置两份函数的环境变量，部署函数、上传触发器，再按第 1 节批准账号。云函数运行身份需能访问上述集合和私有存储。
7. 在微信后台更新实际使用的隐私保护指引：麦克风、腾讯云评测、录音和分数的保存、同档案共享回听及联系/删除方式。

## 7. 验证录音确实保存了

1. 使用 `dad` 档案，在「穿衣与整理」录一条有效跟读，等待真实成绩和星星。
2. 星星出现后可能继续显示 **Saving your recording…**。等保存提示消失，出现 **Play saved**。
3. 退出课程再进入同一题，点击 **Play saved**。可以播放，才说明它不只是当前页的本机录音。
4. 展开 **Scores for grown-ups**，核对 **Saved recording** 对应的是已保存音频的分数。**This time** 是本次分数，**Best** 是历史最高分，三者不一定相同。
5. 用另一档案进入同一题，确认成绩和音频没有串用；同档案的另一个账号则可共同回听。

较低分不替换正式录音，同分选择较新的录制；低分练习结束后，`Play mine` 和 `Play saved` 播放不同录音是正常的。

## 8. 保存失败时如何操作

显示「Your score is saved. Your recording needs another try.」时，留在当前题，点击 **Save recording again**。此操作重用原成绩，不会再调用付费评分。成功后退出并重新进入，验证 **Play saved**。

已发起的自动保存不因切题而取消，但本机临时录音会被清理。若保存尚未成功便关闭小程序或离开后丢失本机录音，不能仅凭分数恢复音频。关闭前等待保存提示消失；需要重试时先在当前页完成。

## 9. 暂停服务和维护数据

临时暂停所有云评分与云回放：将 `speech-evaluate` 的 `SPEECH_ENABLED` 改为 `false`。恢复时改回 `true`。普通听读课程仍可使用；已进入页面可能暂时保留按钮，后续请求会返回关闭状态。

只暂停一个账号，使用第 2 节的 `enabled: false`。暂停清理则修改 `speech-cleanup` 的 `SPEECH_CLEANUP_ENABLED=false`，这不会删除正式录音，但废弃文件可能暂时积累。

当前没有自动备份/导出工具，也没有一键删除档案功能。正式录音不自动过期，长期保留依赖云环境、账号和存储正常续费。不要把清空数据库集合、删除存储目录当作排错手段。需要完整删除某份档案时，先按[技术说明的数据维护章节](speech-evaluation.md#数据维护)核对关联文件和成绩，再安排操作。
