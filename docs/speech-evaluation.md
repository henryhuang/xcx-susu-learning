# 英语跟读、家庭权限与永久录音

日常配置和维护见[录音功能操作指南](speech-operations.md)，报错先查[录音排错指南](speech-troubleshooting.md)。本页说明实现、保存语义及验证方式。

## 当前行为

「穿衣与整理」19 个跟读活动接入腾讯智聆口语评测新版。英语学习页面只用英文；课程内容和学习进度不因录音权限改变。原生录音最长 15 秒、MP3、16kHz、单声道、48kbps，云端校验实际格式和时长，最大 120,000 字节。

新版默认不开放录音。微信账号必须先登记申请，再由家长在云开发数据库手动批准。没有“首个用户自动成为管理员”或客户端批准接口。后台使用 `getWXContext()` 的 OPENID 和本小程序 APPID 校验身份，所有评分、历史、保存、回放均检查白名单。首页只提供「家长录音设置」入口，普通用户仍可听音频和完成课程。

获准账号使用 `speech_family.learnerId` 指定的录音档案：爸爸使用 `dad`，酥酥或妈妈使用 `susu`。相同 ID 共用数据，不同 ID 的成绩、录音和每日额度隔离。ID 仅由后台配置，格式为 1–32 位小写字母、数字、下划线或连字符，以字母开头。新申请默认未绑定档案，必须在批准时填写。每个「档案 + 课程 ID + 课程版本 + 活动 ID」保留一份正式录音：分数更高时替换，同分选择开始录制时间较新的一次；较低分只供当前页面临时回听。成绩摘要长期保存最好分、最近分、有效练习次数；录音保存自己的分数，避免把最新分误认为已保存录音的分数。换题或重开仍可点击 `Play saved` 回听，家长展开分数可查看 `Saved recording`。

正式录音不设自动过期。永久保存依赖云环境、存储和账号正常续费，不能替代独立备份。重新练习仍只保留一份最高分录音。课程版本变化使用独立档案，旧版本不会自动删除。

## 本次升级操作清单（按顺序）

目标环境：`prod-d4gpmzbyg28ead01d`。以下是需要家长在开发者工具或云控制台完成的配置；本地代码修改不会自动完成这些操作。

1. **创建两个数据库集合**：`speech_family`、`speech_recordings`。加上已有的 `speech_quotas`、`speech_attempts`、`speech_summaries`，五个集合均设客户端安全规则：

   ```json
   { "read": false, "write": false }
   ```

2. **云存储权限设为客户端不可读、不可写**：使用自定义安全规则，同样设置 `read: false`、`write: false`。后端使用服务端 SDK 上传和读取。不设置公有读、不建立公开音频链接；检查该环境现有其他文件是否依赖客户端访问，再调整。当前课程图片和示范音频来自小程序包/课程包，不依赖这份私有录音存储。确认没有存储生命周期规则自动过期 `speech/` 下各档案的正式录音。
3. 在已有 `speech-evaluate` 环境变量中新增 **`SPEECH_STORAGE_PRIVATE=true`**。这是对步骤 2 已完成的确认开关，代码无法替你检查控制台安全规则。保留已有 SOE 密钥和开关。
4. 右键 `cloudfunctions/speech-evaluate`，选择**上传并部署：云端安装依赖**。Node.js 18 或更新，内存 **256 MB**，超时 **40 秒**。只允许小程序身份调用，不开 HTTP/匿名触发器。云函数运行身份需具备这五个集合和私有云存储的读写权限。
5. 部署新函数 `cloudfunctions/speech-cleanup`，同样选择云端安装依赖；内存 **256 MB**、超时 **40 秒**。环境变量新增 **`SPEECH_CLEANUP_ENABLED=true`**。在开发者工具右键该目录下的 **`config.json` 文件 → 上传触发器**，确认每小时运行一次。函数部署不等于触发器已上传；入口见[操作指南](speech-operations.md#5-上传定时触发器)。不要给它配置 HTTP 触发器。SDK 依赖锁在各函数 `package-lock.json` 中。
6. 重新编译小程序，首页 → **家长录音设置** → **申请开通此账号**，复制申请码。在 `speech_family` 中按 `requestCode` 找到该条记录，把 `enabled` 改为**布尔值 `true`**；爸爸的 `learnerId` 填字符串 **`dad`**，酥酥或妈妈的账号填 **`susu`**。不要把申请码写进客户端代码。回到设置页点击**刷新权限**，再进入课程。
7. 另一位家人用自己的微信重复步骤 6，配置相同档案 ID 后即可共用录音，配置不同 ID 则隔离。撤销时将对应记录 `enabled` 改为布尔值 `false`；不删除共享档案。页面重新显示、开始录音、保存和云回放时都会重新检查权限。已下载到本机并正在播放的短音频不会远程强制中断。
8. 在微信后台更新隐私保护指引：麦克风、腾讯云发音评测、长期保存录音和分数、获准家人共同回听、联系和删除方式。真机验收后再上传新版小程序；本次没有发布小程序、课程 ZIP 或修改线上 revision。

云存储规则参考：[CloudBase 存储安全规则](https://docs.cloudbase.net/storage/security-rules)。定时触发器参考：[腾讯云定时触发器说明](https://cloud.tencent.com/document/product/583/9708)。

## 将爸爸账号切换到独立档案

1. 更新部署 `speech-evaluate` 和 `speech-cleanup` 两个函数，云端安装依赖；环境变量和现有定时器不变。
2. 小程序「家长录音设置」复制爸爸账号的申请码，在 `speech_family` 找到对应记录，将 `learnerId` 从 `susu` 改为 `dad`，保留 `enabled: true`。
3. 重新编译小程序，设置页刷新，确认「当前录音档案：dad」，退出再进入课程。酥酥/妈妈账号的 `learnerId` 继续用 `susu`。

修改绑定不会移动或删除旧的 `susu` 录音；`dad` 使用独立成绩和录音。档案切换后旧档案的 attempt 不可用于新档案保存或评分，处理中的请求也会校验档案绑定。

## 首次接入与已有环境变量

在微信开发者工具导入仓库根目录 `xcx-susu-learning/`，根配置指定 `miniprogramRoot: miniprogram/`、`cloudfunctionRoot: cloudfunctions/`。选择上述环境后右键函数部署。客户端环境在 `miniprogram/config/speech.js`，环境 ID 是公开标识，不是密钥。腾讯云需开通「智聆口语评测（新版）」英文评测能力；用户已确认此前真机评分可用。

| speech-evaluate 环境变量 | 用途 |
| --- | --- |
| `SPEECH_ENABLED=true` | 开启服务 |
| `SOE_APP_ID` | 腾讯云数字 AppID，区别于微信小程序 AppID |
| `SOE_SECRET_ID` / `SOE_SECRET_KEY` | 仅存后端，用于 SOE 签名 |
| `SPEECH_STORAGE_PRIVATE=true` | 确认存储已经禁止客户端读写 |
| `SPEECH_DAILY_LIMIT=60` | 每份录音档案的每日预约次数，同档案账号合计 |
| `SPEECH_GLOBAL_DAILY_LIMIT=1000` | 环境每日总预约次数上限 |

不要发送密钥到聊天、前端或 Git。函数不打印 event、录音、供应商原始返回、签名 URL；错误日志仅含固定 stage/code。后端不开放 HTTP 接入，避免混用身份来源。腾讯评测方的数据处理按其服务协议执行。

## 评分等待优化

新版小程序评测请求带 `deferRecording: true`：后端取得真实评分并保存成绩后立即返回；客户端显示星星动画，再自动发起独立的 `save-recording` 云调用。界面显示 `Saving your recording…`，成功后更新云回放入口。保存重用原 attempt，不重复评测或计费；低于最高分的练习不上传。旧客户端不传该标志时仍沿用原来的完整保存流程。

独立保存请求持有音频 Base64 和原始 attempt/活动，不依赖切题时会删除的临时文件；切题不取消已发起的保存，迟到的回复不会改变新题界面。保存失败保留分数、旧正式录音，并提供当前题重试。关闭小程序前应等保存提示消失；若程序在独立保存发起前被终止，音频仍可能来不及上传。腾讯评测、网络和冷启动仍耗时，本地测试不能代替真机耗时测量。

启用步骤：重新部署 `speech-evaluate`（云端安装依赖），再重新编译/上传新版小程序。环境变量、数据库、`speech-cleanup` 和定时器无需修改。

## 保存、回放与失败处理

调用链：原生录音 → 云函数评测并保存成绩 → 服务端上传私有云存储 → 数据库事务切换正式录音指针。音频不写入数据库。

- 上传前用服务端生成的路径登记 `speech_recordings` 日志，以便清理中途终止的上传。每次 attempt 使用独立文件路径，不覆盖正式文件。
- 新文件上传完整且该 attempt 仍为最高分时，事务更新摘要指针。旧正式录音才标记为待清理；并发完成顺序不会把较旧的同分录音换回来。
- 上传或指针更新失败，旧正式录音仍保留，成绩已保存。当前页可用 `Save recording again` 重试，复用同一 attempt，不再次调用 SOE。离开后本机临时音频删除；若未保存的新最高分录音丢失，成绩仍保留，但无法恢复该音频。
- `playback` 只接受课程/活动标识，不接受客户端指定文件 ID。后端检查家庭权限和正式指针、校验音频哈希，再返回短音频 Base64；前端写入本机缓存播放，不返回公开或临时下载链接。本机回放文件在换题、隐藏、重录时删除，下次启动补清理意外退出的回放缓存。
- `speech-cleanup` 每次最多处理 20 条到期的临时/替换日志，10 分钟安全期后可删除对应文件。事务先确认文件不被正式指针引用；正式录音不按年龄删除。失败会在之后的定时任务重试。此函数只做精确文件删除，不扫描或清空整个存储空间。
- `history` 首次读取时将该已批准账号的旧版个人成绩幂等合并到首次绑定的档案；已经迁移过的个人成绩不因更改绑定重复导入。旧版没有云录音，因此只能迁移成绩。

`begin` 在事务中预占共享每日和环境额度，三秒间隔，attempt 两分钟有效。取消/静音/失败不退预约额度；预约本身不调用 SOE。有效评分只计算一次，静音和失败不写成 0 分，真实 0 分可保存。三颗显示星：80 分及以上三颗、60–79 分两颗、其余有效分一颗；与课程完成星星独立。

## 数据维护

| 集合 | 内容 |
| --- | --- |
| `speech_family` | OPENID 的哈希 ID、申请码、是否启用、后台指定的档案 ID，如 `dad` / `susu` |
| `speech_summaries` | 共享活动最好/最近成绩、次数、正式录音指针 |
| `speech_attempts` | 预约身份、状态、成绩、音频哈希；无音频正文 |
| `speech_quotas` | 北京时间每日预约计数 |
| `speech_recordings` | 文件路径、存储 ID、上传/激活/替换/删除状态；另含无音频的 `storage-config` |

不要给摘要、正式录音或档案设置 TTL。当前版本不自动清理分数/attempt；避免删除仍用于保存重试的 attempt 或正式录音日志。配额可在过日后另行归档，不清理当日计数。要彻底删除酥酥资料，应先关闭录音、禁用全部家庭成员，在控制台按档案/摘要核对并删除私有文件与关联成绩和日志；仅撤销某位家人不应删除所有家人共用的资料。

依赖检查：当前腾讯官方 `wx-server-sdk@4.0.2` 的上游数据库/HTTP 传递依赖被 npm audit 标记（6 项）。此实现限定数据库字段与路径、不接受任意 URL 或数据库操作对象；本次未强制降级 SDK 或替换其内部依赖。上线维护时仍需跟进上游修复。

## 课程与验收

课程源的 `speech.mode` 只用于有英文文字和示范音频的 `word` / `action`。旧缓存目标须与内置课程 ID、版本、类型、文字、音频一致，才可补足 speech 配置。含义变化需要升级 lesson.version。构建命令会同时生成客户端与后端清单；不手改生成文件。不覆盖已发布 r11，后续课程发布遵循 `docs/course-release.md`。

本地检查（伪数据库和音频服务，不产生腾讯费用）：

```sh
node tools/build-local-courses.js
node tools/validate-courses.js
node miniprogram/tests/smoke.js
node miniprogram/tests/poppy.js
node miniprogram/tests/speech.js
node cloudfunctions/speech-evaluate/test.js
node cloudfunctions/speech-cleanup/test.js
node tools/check-package-size.js
```

真机验收：未批准账号看不到录音且直接调用被拒绝；批准账号录制/真实评分/保存/重新进入回听；相同档案家人共享、不同档案无法读取；低分保留旧音频、同分较新替换；断网保存失败保留旧录音且重试不增加评分次数；撤销后不能再取云录音；定时器仅删替换/废弃文件且保留正式录音。开发者工具还须确认实际主包体积（本地估算接近 2MB 上限）。
