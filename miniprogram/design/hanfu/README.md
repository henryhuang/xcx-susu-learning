# 汉服酥酥素材记录

使用内置 image_gen，根据现有 Poppy 的面部、圆眼镜、短发和画风制作粉色汉服版本。共三张独立透明 PNG：欢迎挥手、打开书本、竖拇指鼓励。

完整生成提示词、参考图与应用文件位置见 `prompts.json`。母图保存在 `originals/`，应用版在 `chinese/assets/images/`；使用 sips 等比缩放至长边 560px，pngquant 压缩并保留透明度。欢迎用于中文课程入口，读书用于听读/解释/跟读及未答对反馈，鼓励用于答对与课程完成。

没有替换原来的英文形象。此目录由 project.config.json 排除，不进入上传包。
