# 《弟子规·入则孝》课程核对记录

核对范围：9 月 11 日、18 日、24 日课程中展示的六组原文。原文字形和顺序均与《入则孝》一致；本次修订的是解释文字。小程序解释面向幼儿，用短句讲出原文的核心意思，生活情境题是应用示例，不充当逐字翻译。

| 原文 | 本次核对要点 |
| --- | --- |
| 父母呼，应勿缓。父母命，行勿懒。 | 呼唤要及时回应；父母交代的事应及时做，不能把“父母命”解释为泛泛的约定。 |
| 父母教，须敬听。父母责，须顺承。 | 认真听教导；做错事受到责备时接受提醒、承认并改正。 |
| 冬则温，夏则凊。晨则省，昏则定。 | 关心父母冬暖夏凉；早晨问安，晚上照料其安稳休息。 |
| 出必告，反必面。居有常，业无变。 | 出门说明去向，回来当面报平安；起居与所做的事保持规律，不随意改变。 |
| 事虽小，勿擅为。苟擅为，子道亏。 | 小事也不应瞒着父母擅自做主；原文强调子女本分，并非仅在“拿不准”时才询问。 |
| 物虽小，勿私藏。苟私藏，亲心伤。 | 小东西也不能私自拿走藏起来；应讲清“私藏”和使父母伤心的关系。 |
